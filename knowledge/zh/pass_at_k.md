## 背景

代码和数学题的评测，常常允许模型尝试多次：只要 $k$ 次里有一次做对就算通过，这个概率叫 **pass@k**。它衡量的是模型「有没有能力做对」，而不只是「第一次就做对」。

最直接的估计是每题恰好采 $k$ 次，看有没有做对的。但这样方差很大：$k = 1$ 时每题只有 0 和 1 两种结果。Codex 论文（Chen et al., 2021）的做法是每题采 $n \ge k$ 次（论文里 $n = 200$），数出正确的次数 $c$，再计算「从这 $n$ 个样本中随机挑 $k$ 个，至少有一个正确」的概率。同一批样本可以同时算出 pass@1、pass@10、pass@100。

在推理模型的 RL 训练里，pass@k 也是常看的曲线：RL 往往让 pass@1 明显上升，pass@k（$k$ 大时）上升得少，甚至下降，这被用来讨论 RL 是在激发已有能力还是在教新能力。

## 核心公式

对一道题，从 $n$ 个样本中不放回地挑 $k$ 个，全部错误的概率是

$$
\frac{\binom{n-c}{k}}{\binom{n}{k}}
$$

$\binom{n-c}{k}$ 是只从 $n - c$ 个错误样本里挑的方式数，$\binom{n}{k}$ 是全部挑法。于是

$$
\text{pass@}k = 1 - \frac{\binom{n-c}{k}}{\binom{n}{k}}
$$

当 $n - c < k$ 时，错误样本不够 $k$ 个，任意挑法都包含正确样本，结果是 $1$。最终指标是对所有题目取平均。

**无偏性**：这个式子对「从真实分布独立采 $k$ 次至少一次正确」的概率是无偏的。直接用 $\hat p = c / n$ 代入 $1 - (1 - \hat p)^k$ 是有偏的：$(1 - \hat p)^k$ 是 $\hat p$ 的凸函数，由 Jensen 不等式，它的期望偏大，pass@k 被低估。

**数值稳定的写法**：把比值展开，约分后只剩 $c$ 项连乘：

$$
\frac{\binom{n-c}{k}}{\binom{n}{k}} = \prod_{i=n-c+1}^{n} \left(1 - \frac{k}{i}\right)
$$

$n = 10000$、$k = 500$ 时 $\binom{n}{k}$ 有上千位，转成浮点数直接溢出，连乘形式每一项都在 $[0, 1]$ 内，不会溢出。

## 用到的 Python 工具

- `math.comb(n, k)`：精确的二项式系数（任意大的整数），适合写参考答案，不适合转成浮点数相除。
- `fractions.Fraction`：精确的有理数运算，测试里用来算准确值。
- `range(n - c + 1, n + 1)`：连乘的下标范围。

## 常见坑

- **对所有 $k$ 都返回 $c / n$**：这只是 pass@1。
- **用 $1 - (1 - c/n)^k$**：相当于有放回地采样，结果偏低，样本数越少偏得越多。
- **先把二项式系数转成浮点数再相除**：$n$ 一大就 `OverflowError`。Python 的整数除法 `int / int` 本身能处理大整数，但连乘形式更通用，也是 Codex 论文给出的 numpy 实现方式。
- **$n - c < k$ 的情况**：连乘的下标此时会经过 $i = k$，那一项是 $0$，结果自然为 $1$；`math.comb(n - c, k)` 也会返回 $0$。但改用 `lgamma` 之类的对数写法时会遇到负数的阶乘，要单独处理。显式写一个分支最清楚。
- **按最好的题取 max，或者把所有题的样本混在一起算**：pass@k 是逐题计算再平均。

## 延伸

- **$n$ 取多大**：$n$ 越大，估计越稳，但采样成本线性增长。只关心 pass@1 时，$n$ 取 4 到 16 已经能显著降低方差，这种做法常被报告为 avg@n 或 mean@n。
- **maj@k（多数投票）**：采 $k$ 个答案，取出现最多的那个，判断它是否正确。它衡量「不借助验证器时能拿到的准确率」，比 pass@k 更接近实际部署，因为 pass@k 假设有一个完美的判题器帮你挑。
- **pass^k**：$k$ 次**全部**做对的概率，用于 Agent 评测（如 τ-bench），衡量稳定性。无偏估计是 $\binom{c}{k} / \binom{n}{k}$。
- **温度的影响**：pass@1 通常在低温度下最好，pass@k（$k$ 大）需要较高温度带来多样性。Codex 论文里不同 $k$ 的最佳温度不同。
- **RL 训练中的含义**：pass@k 高而 pass@1 低，说明模型「会做但不稳定」，正是 RL 可以提升的空间。一组 $G$ 个回答全对或全错的题目在 GRPO 中没有学习信号，这也是 DAPO 动态采样要过滤掉它们的原因。

## 面试追问

1. **为什么不每题只采 $k$ 次直接统计？**
   结果只有 0 和 1，方差很大。采 $n > k$ 次后，对所有 $k$ 子集求平均，同样的样本能给出低方差的估计，还能同时得到多个 $k$ 的值。
2. **为什么 $1 - (1 - c/n)^k$ 是有偏的？**
   $\hat p = c/n$ 是 $p$ 的无偏估计，但 $(1 - \hat p)^k$ 是凸函数，期望不等于 $(1 - p)^k$，由 Jensen 不等式偏大，pass@k 被系统性低估。组合数形式对应不放回抽样，期望恰好等于真实值。
3. **大 $n$ 时怎么避免数值溢出？**
   把组合数的比值约分成 $c$ 项 $1 - k/i$ 的连乘，每项都在 0 到 1 之间；或者在对数空间里求和。
4. **pass@k 和 maj@k 有什么区别？**
   pass@k 假设能从 $k$ 个答案中挑出正确的（需要一个完美验证器），是能力上限；maj@k 用多数投票选一个答案，不需要验证器，更接近真实使用。两者的差距反映了验证器或奖励模型能带来的提升空间。
5. **RL 训练后 pass@1 上升、pass@256 下降，说明什么？**
   一种解释是 RL 把概率集中到模型已经会的解法上，提高了稳定性，但降低了多样性，探索范围变窄。这也是在 RL 中保持熵、提高采样温度的理由之一。
