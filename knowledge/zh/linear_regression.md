## 背景

线性回归是最简单的机器学习模型：用特征的线性组合预测一个实数。这道题用三种方法求解同一个问题，正好串起机器学习的三种基本思路：解析求解、手推梯度、自动求导。

## 核心公式

**模型与损失**（均方误差）：

$$
\hat{y} = X w + b,
\qquad
L(w, b) = \frac{1}{N} \sum_{i=1}^{N} (x_i^{\top} w + b - y_i)^2 = \frac{1}{N} \lVert X w + b - y \rVert^2
$$

**① 闭式解（正规方程）**：给 $X$ 加一列全 $1$，把偏置并进参数：$\tilde{X} = [X,\ \mathbf{1}]$，$\theta = [w;\ b]$。令梯度为零：

$$
\nabla_\theta L = \frac{2}{N} \tilde{X}^{\top} (\tilde{X}\theta - y) = 0
\quad\Longrightarrow\quad
\tilde{X}^{\top} \tilde{X}\, \theta = \tilde{X}^{\top} y
$$

$$
\theta = (\tilde{X}^{\top} \tilde{X})^{-1} \tilde{X}^{\top} y
$$

实践中不直接求逆（矩阵接近奇异时数值不稳定），而是用最小二乘求解器。

**② 梯度下降**：对 $w$、$b$ 分别求导：

$$
\frac{\partial L}{\partial w} = \frac{2}{N} X^{\top} (X w + b - y),
\qquad
\frac{\partial L}{\partial b} = \frac{2}{N} \sum_{i} (x_i^{\top} w + b - y_i)
$$

每步 $w \leftarrow w - \eta\, \partial L / \partial w$，$b$ 同理。学习率 $\eta$ 太大会发散，太小则收敛很慢。

**③ 自动求导**：只写前向和损失，让 `loss.backward()` 算梯度，`optimizer.step()` 更新参数。

三种方法应得到几乎相同的 $w$、$b$。

## 形状

| 量 | 形状 |
| --- | --- |
| `X` | `(N, D)` |
| `y`、预测、误差 | `(N,)` |
| $\tilde{X}$ | `(N, D + 1)` |
| `w` | `(D,)` |
| `b` | 标量 |
| `nn.Linear(D, 1)` 的权重、输出 | `(1, D)`、`(N, 1)` |

## 用到的 PyTorch 操作

- `torch.cat([X, torch.ones(N, 1)], dim=1)`。
- `torch.linalg.lstsq(A, y).solution`：最小二乘解。
- `nn.Linear`、`nn.MSELoss`、`torch.optim.SGD`、`zero_grad` / `backward` / `step`。

## 常见坑

- **闭式解忘了偏置列**：解出的直线被迫过原点。
- **梯度少了因子 $2/N$**：方向没错，但步长被放大了 $N/2$ 倍，很容易发散。
- **`nn.Linear` 的输出没有 `squeeze`**：`(N, 1)` 和 `(N,)` 传给 `MSELoss` 会被广播成 `(N, N)`，只给一个警告，结果却完全错误。
- **返回形状**：`w` 是 `(D,)`、`b` 是标量；`nn.Linear` 的权重是 `(1, D)`，要去掉第一维。
- 闭式解不能用 autograd。

## 延伸

- **为什么 MSE**：假设 $y = Xw + b + \varepsilon$，噪声 $\varepsilon$ 服从独立同分布的高斯分布，则最大化似然等价于最小化平方误差。MSE 不是随手选的，它对应「噪声是高斯」这个假设。
- **损失是凸的**：$L$ 对 $(w, b)$ 是凸二次函数。若 $\tilde{X}$ 列满秩，最优解唯一，所以闭式解、梯度下降、`nn.Linear` 最终会收敛到同一个答案，不依赖 `nn.Linear` 的随机初始化。
- **梯度下降能收敛的学习率**：损失的 Hessian 是常数矩阵

$$
H = \frac{2}{N}\, \tilde{X}^{\top} \tilde{X}
$$

  每步误差沿 $H$ 的第 $k$ 个特征方向乘以 $(1 - \eta \lambda_k)$，所以需要 $\eta < 2/\lambda_{\max}$ 才不发散；收敛速度由最慢的方向决定，条件数 $\lambda_{\max}/\lambda_{\min}$ 越大越慢。特征尺度差异悬殊时（比如一个特征是 $1$ 量级、另一个是 $10^3$ 量级）梯度下降会非常慢，所以实践中先做特征标准化。
- **计算量**：闭式解约为 $O(N D^2 + D^3)$，$D$ 很大时不可行；梯度下降每步 $O(N D)$，还能换成 mini-batch（SGD），只用一小批样本估计梯度。
- **数值稳定性**：直接算 $(\tilde{X}^{\top} \tilde{X})^{-1}$ 会把条件数平方（$\kappa(\tilde{X}^{\top}\tilde{X}) = \kappa(\tilde{X})^2$）。最小二乘求解器通常基于 QR 或 SVD 分解，直接处理 $\tilde{X}$，精度更好。
- **正则化（岭回归）**：给损失加 $\lambda \lVert w \rVert^2$，闭式解变成

$$
w = (X^{\top} X + N\lambda I)^{-1} X^{\top} y
$$

  （这里假设 $X$、$y$ 已中心化、偏置单独处理；偏置通常不惩罚。）加上 $\lambda I$ 之后矩阵一定可逆，能处理特征共线的情形。它和深度学习里的 weight decay 是同一个想法。
- **$N < D$ 的情形**：方程组欠定，有无穷多个解。从零向量出发做梯度下降，会收敛到其中范数最小的那个，这是一种「隐式正则化」。

## 面试追问

1. **闭式解和梯度下降各适合什么场景？**
   特征维度不大时闭式解一步到位、没有超参数；维度很大、样本很多或模型不是线性时，闭式解的 $O(D^3)$ 求解不可行（或根本不存在），要用梯度下降及其随机版本。
2. **为什么实践中不直接求 $(X^{\top}X)^{-1}$？**
   求逆很贵，而且矩阵接近奇异（特征共线）时数值不稳定，还会把条件数平方。应该用基于 QR / SVD 的最小二乘求解器，或者加正则项。
3. **为什么线性回归用 MSE 作损失？**
   它是高斯噪声假设下的极大似然估计；同时它对参数是凸的，只有一个全局最优，优化最省心。代价是对离群点敏感，数据里有离群点时可以考虑 Huber 损失。
4. **梯度下降的学习率怎么选？特征标准化有什么用？**
   学习率必须小于 $2/\lambda_{\max}(H)$，否则发散；太小则收敛慢。标准化让 $H$ 的特征值更接近，条件数变小，可以用更大的学习率，收敛也更快。
5. **特征共线或 $N < D$ 时会怎样？怎么办？**
   $\tilde{X}^{\top}\tilde{X}$ 奇异，解不唯一。加 L2 正则（岭回归）可以让解唯一；用伪逆 / 最小二乘求解器会得到最小范数解。
