## 背景

**ALiBi**（Attention with Linear Biases）完全不用位置向量，而是在注意力分数上直接加一个**与距离成正比的惩罚**：离得越远，分数扣得越多。它很简单，而且推理时可以处理比训练时更长的序列（外推性好）。BLOOM、MPT 等模型使用它。

## 核心公式

在标准缩放点积分数上加偏置，再做 softmax：

$$
\text{scores}_{h,i,j} = \frac{q_{h,i} \cdot k_{h,j}}{\sqrt{d_h}} \;-\; m_h \cdot |i - j|
$$

每个头 $h$ 有自己的**斜率** $m_h$，按几何级数排列（$H$ 为头数）：

$$
m_h = \frac{1}{2^{8h/H}} = 2^{-8h/H}, \qquad h = 1, 2, \dots, H
$$

例如 $H = 8$ 时，斜率为 $\tfrac12, \tfrac14, \dots, \tfrac{1}{256}$。斜率大的头只关注附近的 token，斜率小的头能看得更远，各头分工覆盖不同距离。

**为什么 softmax 前加偏置等于乘权重**：

$$
\operatorname{softmax}(s_j - m\,d_j) \propto e^{s_j} \cdot e^{-m\, d_j}
$$

即把第 $j$ 个位置原本的注意力权重乘上一个随距离指数衰减的因子，再重新归一化。

## 形状

| 量 | 形状 |
| --- | --- |
| `Q`、`K`、`V` | `(B, S, D)` |
| 拆头后 | `(B, H, S, d_h)`，$d_h = D / H$ |
| 斜率 $m$ | `(H,)` → `(H, 1, 1)` |
| 距离 $\lvert i - j \rvert$ | `(S, S)` |
| 偏置 | `(H, S, S)` → 广播为 `(1, H, S, S)` |
| 分数 | `(B, H, S, S)` |

## 用到的 PyTorch 操作

- `pos.unsqueeze(0) - pos.unsqueeze(1)`：广播得到 $S \times S$ 的差值矩阵；`.abs()` 取绝对值。
- `t.view(H, 1, 1)`、`t.unsqueeze(0)`：调整维度以便广播。
- 拆头、合头同多头注意力：`view` + `transpose` + `reshape`。

## 常见坑

- **$h$ 从 $0$ 开始**：$h = 0$ 会得到斜率 $1$，整组斜率都错位了。
- **符号写反**：偏置是 $-m_h \lvert i-j \rvert$，是惩罚。
- **偏置加在 softmax 之后**：必须加在 softmax 之前的分数上。
- **广播维度对不上**：偏置 `(H, S, S)` 要对齐分数的 `(B, H, S, S)`，在最前面补 batch 维，而不是在中间。
- 本题的距离是对称的 $|i - j|$，没有因果掩码。

## 延伸

- **位置信息只在分数里**：输入嵌入不加位置向量，$q$、$k$、$v$ 也不改，位置只通过一个固定的偏置项进入。没有可学习参数，也不需要三角函数表。
- **因果情形下只依赖 key 的位置**：ALiBi 原本用于自回归模型，对 $j \le i$ 偏置是 $-m(i-j)$。softmax 对同一行的所有元素加同一个常数不变，而 $-m(i-j) = m j - m i$，其中 $-m i$ 对这一行是常数，所以等价于只加 $m j$。本题是无掩码的对称版本 $\lvert i-j \rvert$，没有这个简化。
- **斜率是固定的**：不学习，由头数决定。斜率大的头偏置增长快，只看近处；斜率小的头偏置平缓，能看得更远。头数不是 $2$ 的幂时，论文有一条专门的补全规则。
- **外推**：训练时偏置只出现过有限的距离，但偏置是距离的线性函数，任意距离都能直接算出，不存在「没有位置向量可用」的情况。论文的标题就是 *Train Short, Test Long*。不过外推的程度会随任务和序列长度而变，后来更多开源大模型选择了 RoPE 再配合上下文扩展。
- **显存与速度**：朴素实现要生成一个 `(H, S, S)` 的偏置，显存随序列长度平方增长。FlashAttention 系列的 kernel 支持直接传入斜率，在 kernel 内部按块算偏置，不用把整个偏置矩阵写进显存。
- **局限**：惩罚随距离线性增加，是一个很强的「越近越重要」先验。需要精确回看很远处某个 token 的任务，要靠斜率小的那些头来完成。
- **对比**：与 T5 相对偏置（可学习的分桶标量）、RoPE 的比较见「位置编码」专题。

## 面试追问

1. **ALiBi 为什么不需要位置嵌入也能知道顺序？**
   位置信息在注意力分数里：离得越远扣分越多，所以每个 token 能区分近的和远的。因果模型里还可以从每个 token 只看得到前缀这一点得到位置信号。
2. **不同的头为什么用不同的斜率？**
   斜率决定「关注半径」。几何级数排列的斜率让各个头覆盖从很近到较远的不同尺度，类似多头注意力里头的分工。如果所有头用同一个斜率，就只有一种尺度。
3. **偏置加在 softmax 前和 softmax 后有什么不同？**
   加在前面等价于把注意力权重乘上 $e^{-m d}$ 再重新归一化，权重之和仍是 $1$。加在后面就变成了不归一化的权重，输出的尺度会随距离分布变化，也不再是 ALiBi。
4. **因果注意力下，ALiBi 的偏置为什么可以只依赖 key 的位置？**
   因为 $-m(i-j) = m j - m i$，其中 $-m i$ 对 softmax 的同一行是常数，被归一化消掉。
5. **ALiBi 和 RoPE 比，各有什么特点？**
   ALiBi 更简单，没有三角函数，不改 $q$、$k$，适合训练短、推理长；RoPE 没有距离先验，由模型自己学，目前更主流，配合 NTK、YaRN 等方法可以扩展上下文。
