## 背景

**消息传递神经网络**（MPNN，Gilmer 等 2017，用于预测分子性质）给出了 GNN 的统一框架：一层分三步：

1. **消息**（message）：每条边根据两端节点（和边本身）的特征算出一条消息
2. **聚合**（aggregate）：每个节点把收到的消息汇总
3. **更新**（update）：用自己的旧特征和汇总的消息算出新特征

GCN、GIN、GAT 都是它的特例，区别只在于这三个函数怎么选。MPNN 的一般形式还能利用**边特征**，比如分子中化学键的类型（单键、双键……）。

## 核心公式

**消息**：拼接接收节点 $i$、发送节点 $j$ 和边 $(i, j)$ 的特征，经过线性层和 ReLU：

$$
m_{ij} = \operatorname{ReLU}\bigl([\, x_i \,\Vert\, x_j \,\Vert\, e_{ij} \,]\, W_{\text{msg}}\bigr)
$$

**聚合**（求和，只对邻居）：

$$
\bar{m}_i = \sum_{j \in \mathcal{N}(i)} m_{ij} = \sum_{j} A_{ij}\, m_{ij}
$$

**更新**：

$$
x'_i = \operatorname{ReLU}\bigl([\, x_i \,\Vert\, \bar{m}_i \,]\, W_{\text{upd}}\bigr)
$$

**对应关系**：比如 GIN 就是消息 $m_{ij} = x_j$、聚合求和、更新 $\operatorname{MLP}((1+\epsilon)x_i + \bar{m}_i)$。

## 形状

用广播一次算出所有节点对的消息：

| 量 | 形状 |
| --- | --- |
| `X` | `(N, F)` |
| `E` | `(N, N, D_e)` |
| $x_i$ 沿列复制 | `(N, N, F)`，第 $(i, j)$ 个位置是 $x_i$ |
| $x_j$ 沿行复制 | `(N, N, F)`，第 $(i, j)$ 个位置是 $x_j$ |
| 拼接后 | `(N, N, 2F + D_e)` |
| 消息 | `(N, N, F_msg)` |
| 聚合（对 $j$ 求和） | `(N, F_msg)` |
| 更新输入 | `(N, F + F_msg)` |
| 输出 | `(N, F_out)` |

这种稠密写法需要 $O(N^2)$ 的显存；真实的大图会用边列表只计算存在的边。

## 用到的 PyTorch 操作

- `X.unsqueeze(1).expand(N, N, F)`：第 $i$ 行全是 $x_i$；`X.unsqueeze(0).expand(N, N, F)`：第 $j$ 列全是 $x_j$。`expand` 不复制数据。
- `torch.cat([...], dim=-1)`。
- `msgs * A.unsqueeze(-1)`：用邻接矩阵屏蔽非边，`(N, N, 1)` 广播到消息的最后一维。
- `.sum(dim=1)`：对发送方 $j$ 求和。

## 常见坑

- **忘了屏蔽非边**：在非边的位置，$x_i$、$x_j$ 照样非零，算出的消息也不为零，会被错误地加进聚合结果。只把边特征 `E` 置零是不够的，要在算出消息之后乘以 $A$。
- **拼接顺序**：$[x_i, x_j, e_{ij}]$，与 $W_{\text{msg}}$ 的行对应，顺序错了结果就不对。
- **求和维度错**：节点 $i$ 收到的消息在第 $i$ 行，沿 `dim=1`（$j$）求和。
- **更新时拼接顺序**：$[x_i, \bar{m}_i]$。
- 没有边的图：所有消息被屏蔽，聚合结果为零，仍应正常输出。

## 延伸

- **原论文的设计**：Gilmer 等人的 MPNN 用于预测分子性质（QM9 数据集）。消息函数把两端节点和边特征一起输入，更新函数用 GRU，读出函数用 Set2Set（一种对集合做注意力读出的方法）。本题的消息、更新是简化的线性层加 ReLU。
- **线性层可以拆开**：消息里的线性变换作用在拼接 $[x_i \Vert x_j \Vert e_{ij}]$ 上，等价于三个线性变换的和：$x_i W_a + x_j W_b + e_{ij} W_c$。这样 $x_i W_a$、$x_j W_b$ 只需对每个节点算一次，再广播相加，不用真的构造 $(N, N, 2F + D_e)$ 的大张量（GAT 里的分数分解是同一个思路）。ReLU 要等相加之后再作用。
- **稠密与稀疏**：稠密写法需要 $O(N^2)$ 的显存存所有节点对的消息；稀疏写法只为存在的边算消息，再用 `index_add_` 或 scatter 把消息加到接收节点上，代价与边数成正比。
- **边特征从哪来**：分子里是键的类型（单键、双键、芳香键）、是否在环中，三维模型里还会加原子间距离。有的模型也会更新边的表示，而不只是节点。
- **聚合必须与顺序无关**：求和、均值、最大值都可以，但不能依赖邻居的排列顺序，否则对图的节点编号就不再稳定。
- 框架如何统一 GCN、GraphSAGE、GAT、GIN，见「图神经网络」专题。

## 面试追问

1. **MPNN 的一层包含哪几步？**
   消息：边上根据两端节点和边特征算消息；聚合：每个节点把收到的消息用求和之类的置换不变操作汇总；更新：用自己的旧特征和汇总的消息算新特征。
2. **为什么聚合函数必须置换不变？**
   图的节点没有固定顺序，同一张图换一种编号，结果不应该变。聚合只依赖邻居的集合，不依赖它们的排列，才满足这一点。
3. **MPNN 比 GCN 多了什么？**
   一是显式使用边特征；二是消息函数可以依赖接收方和发送方两端的特征，而不只是发送方；GCN 的消息只由发送方的特征乘固定系数决定。
4. **堆叠 $L$ 层 MPNN 之后，每个节点看到的范围是多大？有什么问题？**
   $L$ 跳以内的邻域。层数多了可能出现过平滑，邻域指数增长又会让信息被挤压到固定长度的向量里（过挤压），长程依赖难以学到。
5. **稠密实现和稀疏实现的区别？**
   稠密实现对所有 $N^2$ 个节点对算消息，再用邻接矩阵屏蔽，显存是 $O(N^2)$。稀疏实现只对存在的边算消息，再按接收节点累加，代价与边数成正比，是大图上的实际做法。
