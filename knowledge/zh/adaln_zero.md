## 背景

**DiT**（Diffusion Transformer，Sora、SD3 的基础架构）用 Transformer 代替 U-Net 做去噪网络。每个块都需要知道「现在是第几个时间步」「要生成哪一类」，即**条件信息**。

**adaLN**（自适应层归一化）的做法：LayerNorm 本来有可学习的缩放 $\gamma$ 和平移 $\beta$，现在不再是固定参数，而是由条件嵌入**回归**出来，每个样本各不相同。**adaLN-Zero** 再加一个门控 $\alpha$ 控制残差分支的输出，并把它初始化为 $0$。

## 核心公式

**回归调制参数**：条件嵌入 $c$（时间步嵌入 + 类别嵌入）经过一个线性层，得到 6 组参数：

$$
[\gamma_1, \beta_1, \alpha_1, \gamma_2, \beta_2, \alpha_2] = c\, W + b
$$

**调制**（本题实现第一组）：

$$
\operatorname{LN}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}},
\qquad
\text{out} = \alpha_1 \odot \bigl(\gamma_1 \odot \operatorname{LN}(x) + \beta_1\bigr)
$$

这里的 LayerNorm 没有自己的可学习参数。

**在完整 DiT 块中**，两组参数分别用于注意力和 MLP 两个子层：

$$
\begin{aligned}
x &\leftarrow x + \alpha_1 \odot \operatorname{Attn}\bigl(\gamma_1 \odot \operatorname{LN}(x) + \beta_1\bigr) \\
x &\leftarrow x + \alpha_2 \odot \operatorname{MLP}\bigl(\gamma_2 \odot \operatorname{LN}(x) + \beta_2\bigr)
\end{aligned}
$$

**为什么零初始化**：$W$、$b$ 初始化为 $0$，则 $\alpha = 0$，每个残差分支的输出都是 $0$：

$$
x + \underbrace{0 \odot f(\cdot)}_{= 0} = x
$$

训练开始时每个块都是**恒等映射**，信号和梯度可以无损地穿过很深的网络，训练更稳定。网络在训练中再逐渐学会「打开」每个分支。

## 形状

| 量 | 形状 |
| --- | --- |
| `x` | `(B, N, D)` |
| `cond` | `(B, D)` |
| `W_ada`、`b_ada` | `(D, 6D)`、`(6D,)` |
| 回归出的参数 | `(B, 6D)`，切成 6 块，每块 `(B, D)` |
| 每块 `unsqueeze(1)` 后 | `(B, 1, D)`，广播到所有 $N$ 个 token |

## 用到的 PyTorch 操作

- `t.chunk(6, dim=-1)`：沿最后一维均分成 6 块。
- `t.unsqueeze(1)`：每个样本的调制参数作用于它的所有 token。
- `x.mean(dim=-1, keepdim=True)`、`x.var(dim=-1, keepdim=True, unbiased=False)`。

## 常见坑

- **没有 `unsqueeze(1)`**：`(B, D)` 和 `(B, N, D)` 直接相乘会按错误的维度广播，或者报错。
- **6 块的顺序**：$\gamma_1, \beta_1, \alpha_1, \gamma_2, \beta_2, \alpha_2$。
- **LayerNorm 的细节**：有偏方差、$\epsilon = 10^{-6}$ 加在根号内。
- 原始 DiT 论文用 $(1 + \gamma)$ 作缩放，让零初始化时缩放为 $1$；本题按题面直接用 $\gamma$。

## 延伸

**和普通 LayerNorm 的关系**：LayerNorm 自带的 $\gamma$、$\beta$ 是对所有输入共享的固定参数（见「归一化」专题）；AdaLN 把它们换成条件的函数，每个样本一组，归一化本身不再带参数。这属于 FiLM（Perez 等，2018）一类的条件调制：用条件向量逐通道地缩放、平移特征。

**条件向量和线性层**：DiT 里条件 $c$ 是时间步嵌入与类别嵌入之和。时间步先做正弦编码，再过一个小 MLP；回归调制参数的线性层前面还有一个 SiLU。本题只实现其中的「线性回归 + 调制」，不包括这两步。

**参数量代价**：每个块里回归 6 组参数的线性层是 $D \to 6D$，约 $6D^2$ 个参数。块里的注意力约 $4D^2$，MLP（扩张比 4）约 $8D^2$，所以这个线性层占整个块参数的三分之一左右。也有工作（如 PixArt-α 的 adaLN-single）让各块共享一部分调制参数来节省。

**零初始化的来源与效果**：思路来自 ResNet 里把每个残差块最后一个 BatchNorm 的 $\gamma$ 初始化为 $0$（Goyal 等，2017）：这样每个块起点就是恒等映射，网络从浅到深逐步长出来，深层也能稳定地开始训练。DiT 里不仅 $\alpha$，回归参数的线性层整体初始化为 $0$，网络最后的输出层也是零初始化。

**零初始化为什么不会让梯度为零**：初始时 $\alpha = 0$，输出 $\alpha \odot f(\cdot)$ 对 $\alpha$ 的梯度正比于分支输出 $f(\cdot)$，不是零，所以回归 $\alpha$ 的线性层第一步就能更新。分支内部（注意力、MLP）的参数梯度要乘 $\alpha$，起点确实是零，但 $\alpha$ 一旦偏离零，它们也开始学习。残差流 $x$ 本身的梯度没有被截断。

**为什么常用 $(1 + \gamma)$**：这样 $\gamma = 0$ 对应缩放为 $1$，零初始化的调制参数给出「普通归一化」，更符合直觉。本题按题面直接用 $\gamma$，没有 $1 +$ 这一项。

**按样本而不是按 token 调制**：条件是一个全局向量，每个样本的 6 组参数对该样本的所有 $N$ 个 token 一视同仁。因此条件注入的开销与 token 数无关，只和 batch 大小有关。

**对比其他注入方式**：把条件拼成额外 token 的做法（in-context）会拉长序列；交叉注意力要额外的注意力层，算力开销更大；DiT 论文中比较了这几种方式和 AdaLN，AdaLN-Zero 效果最好。对文本这样需要逐 token 对齐的条件，SD3 的 MMDiT 则让文本 token 和图像 token 在注意力里拼在一起，AdaLN 式的调制保留给时间步等全局信息（见「扩散与流匹配」专题）。

## 面试追问

1. **adaLN-Zero 相比 adaLN 多了什么？为什么要零初始化？**
   多了一个门控 $\alpha$，乘在每个残差分支的输出上，并且初始化为 $0$。这样每个 DiT 块在训练开始时是恒等映射，信号和梯度无损穿过很深的网络，训练更稳定。DiT 论文中它也是几种条件注入方式里效果最好的。
2. **$\alpha$ 初始为 $0$，梯度会不会传不下去？**
   不会。$\alpha$ 的梯度正比于分支输出，不是零，所以 $\alpha$ 在第一步就会更新；残差流上的恒等路径也保证了梯度能传到更前面的层。分支内部参数的梯度因为乘了 $\alpha$ 起点为零，但随 $\alpha$ 变大立即恢复。
3. **为什么用 AdaLN 注入时间步和类别，而不是拼接或交叉注意力？**
   时间步、类别是全局向量，不需要和每个 token 单独对齐。AdaLN 只增加一个线性层，计算量远小于交叉注意力，也不会增加序列长度。对需要精细对齐的文本条件，则更多使用注意力。
4. **AdaLN 里的 LayerNorm 为什么不要自己的 $\gamma$、$\beta$？**
   缩放和平移由条件回归，再保留一组固定的可学习参数就多余了，还会和调制参数重复。因此这里的 LayerNorm 只做减均值、除标准差。
5. **DiT 与 UNet 去噪网络相比有什么优缺点？**
   DiT 结构统一、继承 Transformer 的扩展规律，加深加宽后效果可预测地变好，也便于与语言模型的工具链共用。代价是自注意力对 token 数是平方复杂度，高分辨率下要靠潜空间、更大的 patch 或高效注意力来控制成本；UNet 的卷积带有局部性等归纳偏置，小数据、小模型时更省心。
