## 解决什么问题

现代语言模型是同一种块的重复堆叠。几乎所有块都符合下面的模板：

$$
x \leftarrow x + \operatorname{Mixer}\bigl(\operatorname{Norm}(x)\bigr)
$$

$$
x \leftarrow x + \operatorname{FFN}\bigl(\operatorname{Norm}(x)\bigr)
$$

- **Mixer** 负责在 token 之间交换信息：注意力，或者状态空间模型（SSM）。
- **FFN** 对每个 token 单独做非线性变换：稠密的 MLP，或者混合专家（MoE）。
- 残差连接和归一化让几十上百层叠起来之后仍能训练。

这个专题的每道题都是在这个模板上动一处：

- GPT-2 Block：模板本身。
- MoE、MoE 负载均衡：换掉 FFN。
- Mamba：换掉 Mixer。
- 多 Token 预测：不改块，改输出端的训练目标。

动机都是同一个：参数量、每个 token 的计算量、训练和推理的显存与带宽，在稠密 Transformer 里互相绑定。MoE 把「参数量」和「计算量」解开，SSM 把「推理状态」和「序列长度」解开，MTP 则让每个位置多提供一些监督信号。

## 对比

| 方案 | 改动的地方 | 得到什么 | 代价 | 代表 |
| --- | --- | --- | --- | --- |
| 稠密 Transformer | 无 | 简单、成熟 | 参数和算力绑定；KV 缓存随长度增长 | GPT-2、LLaMA |
| MoE | FFN 换成多个专家 | 总参数大，每 token 算力不变 | 显存放全部专家；要做负载均衡和通信 | Mixtral、DeepSeek-V3 |
| SSM / Mamba | 注意力换成选择性 SSM | 训练线性于长度；推理状态固定 | 固定状态，精确回溯弱 | Mamba；Jamba（混合） |
| MTP | 输出端多个头 | 监督更密；可做推测解码草稿 | 额外的头和 logits | Meta 2024；DeepSeek-V3 |

## 演进

1. **原始 Transformer（2017）** 是 Post-LN 的编码器-解码器结构。GPT 系列只保留解码器，**GPT-2（2019）** 把 LayerNorm 移到子层之前（Pre-LN），并在最后加一个 final LN。
2. **LLaMA 式 block（2023 年起成为默认）**：逐项替换成更省、更稳的组件，见下一节。
3. **稀疏化（MoE）**：GShard（2020）、Switch Transformer（2021）把 MoE 引入 Transformer，并提出辅助损失来防止路由坍缩；之后 Mixtral 等开源模型让它普及；DeepSeekMoE（2024）加入细粒度专家和共享专家，DeepSeek-V3 进一步用偏置做无辅助损失的负载均衡。
4. **线性递推（SSM）**：S4（2021）让 SSM 能处理长序列；Mamba（2023）引入选择性；Mamba-2（2024）与注意力建立联系；Jamba（2024）等把 Mamba 层和注意力层混合使用。
5. **训练目标**：从只预测下一个 token，到多 token 预测（2024）。

## 从 GPT-2 block 到 LLaMA 式 block

| 组件 | GPT-2 | LLaMA 式 | 见 |
| --- | --- | --- | --- |
| 归一化 | Pre-LayerNorm | Pre-RMSNorm | 「归一化」专题 |
| 位置信息 | 可学习的绝对位置嵌入，加在输入上 | RoPE，作用在每层的 $q$、$k$ 上 | 「位置编码」专题 |
| 注意力 | MHA | MHA 或 GQA（LLaMA 2 的 70B 起用 GQA） | 「注意力」专题 |
| MLP | 两个矩阵，隐层 $4d$，GELU | 三个矩阵，隐层约 $\frac{8}{3}d$，SwiGLU | 「基础层与激活」专题 |
| 偏置 | 有 | 通常没有 | |

三个矩阵、隐层 $\frac{8}{3}d$ 是为了让参数量和 $4d$ 的两矩阵 MLP 持平：$3 \cdot d \cdot \frac{8}{3}d = 8d^2 = 2 \cdot d \cdot 4d$。

骨架没变，仍然是上面的模板，换的是每个零件。这些零件各自的细节见对应专题，GPT-2 Block 一题只要求实现最原始的那一版。

## 稠密对比 MoE

| | 稠密 FFN | MoE（$E$ 个专家，top-$k$） |
| --- | --- | --- |
| FFN 总参数 | $P$ | 约 $E \cdot P$ |
| 每 token 激活的 FFN 参数 | $P$ | 约 $k \cdot P$ |
| 推理显存 | 放全部参数 | 放全部专家，不因激活少而省 |
| 额外组件 | 无 | 路由器、负载均衡 |
| 多卡通信 | 张量并行 / 数据并行 | 还要加专家并行的 all-to-all |

具体数字：Mixtral 8×7B 总参数约 47B、每个 token 激活约 13B；DeepSeek-V3 总参数 671B、每个 token 激活 37B。计算量只看激活参数，显存要放下总参数，这是 MoE 最重要的权衡。

### 路由和负载均衡

路由器给每个专家打分 $\ell = xW_r$，取 top-$k$，在选中的分数上做门控。两个问题接着出现：

- **路由坍缩**：少数专家越练越强，越被偏爱。解法一是**辅助损失**：

$$
L_{\text{aux}} = E \sum_{i=1}^{E} f_i P_i
$$

  $f_i$ 是实际分到专家 $i$ 的 token 比例，$P_i$ 是平均路由概率。解法二是 DeepSeek-V3 的**无辅助损失**方法：给每个专家一个偏置，只用于选择，过载的调低、欠载的调高，不产生额外梯度。
- **专家专门化不足**：每个专家都想学全部知识。解法是**细粒度专家**加**共享专家**，共享专家处理所有 token 的通用部分，路由专家只负责专门的部分。

|  | 辅助损失 | 偏置（无辅助损失） |
| --- | --- | --- |
| 做法 | 在主损失上加一项 | 偏置按负载调整，不进梯度 |
| 优点 | 简单，可微 | 不干扰主任务 |
| 缺点 | 系数难调，均衡和质量折中 | 要额外维护偏置和步长 |

两者也可以同时使用。

## Transformer 对比 SSM

注意力每一步都回看整段历史；SSM 把历史压缩进一个固定大小的状态，每步只更新它：

$$
h_t = \bar{A}_t \odot h_{t-1} + \bar{B}_t \odot x_t,
\qquad
y_t = C_t \cdot h_t
$$

| | 注意力 | Mamba |
| --- | --- | --- |
| 训练计算 | $O(S^2)$ | $O(S)$，用并行扫描 |
| 推理每步 | $O(S)$，要读整个 KV 缓存 | $O(1)$ |
| 推理状态 | KV 缓存，随长度线性增长 | 固定大小 |
| 精确回溯历史 | 强 | 弱，状态是有损压缩 |
| 硬件与生态 | 成熟 | 需要专门的扫描 kernel |

线性注意力的状态更新是同一类递推，区别是 Mamba 的衰减因子由输入决定，能主动遗忘（见「注意力」专题的线性注意力一题）。

## 怎么选

- **通用大模型，追求稳妥**：稠密的 LLaMA 式 block（Pre-RMSNorm、RoPE、GQA、SwiGLU）。
- **想在训练算力不变时提高模型容量**：MoE。要接受显存按总参数计、需要专家并行和负载均衡的复杂度。
- **推理成本主要是 KV 缓存，长序列、长生成**：考虑 SSM；需要精确检索长上下文的任务，则用 SSM 与注意力的混合。
- **想让训练信号更密，或者想要免费的推测解码草稿**：加上 MTP，代价是额外的头和 logits 开销。

这几个方向相互正交，可以叠加使用，例如 DeepSeek-V3 同时用了 MoE 和 MTP，Jamba 同时用了 Mamba、注意力和 MoE。

## 题目顺序

1. **GPT-2 Block**：先把整个块搭起来，熟悉 Mixer + FFN + 残差 + 归一化的模板，以及因果掩码。
2. **MoE**：在这个模板上换掉 FFN，写路由和按专家分组的计算。
3. **MoE 负载均衡损失**：路由器的训练会坍缩，补上辅助损失。
4. **多 Token 预测**：回到块的输出端，改训练目标，同时练手写稳定的交叉熵。
5. **Mamba SSM 步骤**：换掉 Mixer，看固定状态的递推是怎么回事。

## 面试追问

1. **MoE 的「总参数」和「激活参数」是什么？为什么说它把参数量和计算量解耦了？**
   总参数是所有专家加共享部分的总和，激活参数是单个 token 实际用到的那部分，只有 top-$k$ 个专家。计算量跟激活参数成正比，容量跟总参数相关，所以可以在不增加每 token 算力的情况下扩大容量。代价是显存要按总参数算。
2. **MoE 的负载均衡为什么重要？有哪些做法？**
   不均衡会让部分专家得不到训练，也会让专家并行时个别 GPU 过载拖慢整步。做法有：辅助损失、给每个专家加偏置的无辅助损失方法、给专家设容量上限并丢弃超出的 token。
3. **从 GPT-2 到 LLaMA，block 改了哪些地方？**
   LayerNorm 换成 RMSNorm，绝对位置嵌入换成 RoPE，MHA 逐步换成 GQA，GELU 的 MLP 换成 SwiGLU，并去掉偏置。Pre-Norm 的残差结构没变。
4. **Mamba 和 Transformer 的取舍是什么？**
   Mamba 训练线性、推理 $O(1)$ 且状态固定，但固定状态是有损压缩，精确回溯长上下文弱于注意力。折中是混合架构。
5. **多 Token 预测和推测解码有什么关系？**
   MTP 的额外头可以一次猜出后面几个 token，主模型再用一次前向验证，猜对的保留，相当于自带草稿模型。MTP 也可以只当训练辅助，推理时丢掉额外的头。
6. **同样激活参数量下，MoE 一定比稠密模型更好吗？**
   不一定。MoE 的收益依赖路由训得好、负载均衡得当；推理时还要付出显存和通信的代价。所以 MoE 常用在算力受限、显存和互联条件允许的大规模训练与服务场景中。
