## 解决什么问题

图像是 `(C, H, W)` 的规则网格，像素很多，而且有两个强规律：**相邻像素相关**（局部性），**同一种模式出现在哪里都是同一种模式**（平移对称）。如果把图像展平后接全连接层，参数量随像素数平方增长，还完全浪费了这两条规律。视觉模型的共同思路是：**用一个小的、共享权重的算子在整张图上滑动，每个位置只看一小块邻域**，再逐层堆叠，把局部特征聚合成全局表示。

卷积是这个思路的原型，本专题的其他算子都是它的变体：

$$
y_{o,i,j} = \beta_o + \sum_{c}\sum_{u,v} x_{c,\, is+u,\, js+v}\; W_{o,c,u,v}
$$

池化把「加权求和」换成「取最大」，深度可分离卷积把求和范围拆开，patch embedding 是步长等于核大小的卷积，ViT 则干脆把「只看邻域」换成「看所有 patch」。

## 对比

| 算子 | 做什么 | 参数量 | 乘加量（MACs） | 典型使用 |
| --- | --- | --- | --- | --- |
| 标准卷积 | 空间聚合 + 通道混合 | $C_o C_i k^2$ | $C_o C_i k^2 \cdot H_o W_o$ | ResNet 等 CNN |
| 深度卷积 | 只做空间聚合 | $C_i k^2$ | $C_i k^2 \cdot H_o W_o$ | MobileNet、ConvNeXt |
| 逐点卷积 | 只做通道混合 | $C_o C_i$ | $C_o C_i \cdot H_o W_o$ | 同上，等价于逐像素的 Linear |
| 最大池化 | 下采样，取窗口最大 | 0 | 无乘加，只做比较 | CNN 的下采样 |
| Patch embedding | 切块 + 线性投影 | $d\,C P^2$ | $N \cdot d\,C P^2$ | ViT 的输入层 |

$C_i$、$C_o$ 是输入、输出通道数，$k$ 是核大小，$H_o \times W_o$ 是输出的空间大小，$P$ 是块大小，$N$ 是块数，$d$ 是嵌入维度。深度卷积加逐点卷积合起来就是深度可分离卷积，二者的比值见下一节。

### 尺寸、参数量与感受野

- **输出尺寸**：核大小 $k$、步长 $s$、填充 $p$ 时，$H_{\text{out}} = \lfloor (H + 2p - k)/s \rfloor + 1$。奇数核取 $p = (k-1)/2$ 且 $s=1$ 时尺寸不变。池化是 $p=0$ 的特例。带膨胀率（dilation）$d$ 的卷积，把 $k$ 换成 $d(k-1)+1$。
- **感受野**（receptive field，输出上一个点能看到的输入范围）：逐层递推，$r_l$ 是第 $l$ 层的感受野，$j_l$ 是相邻两个输出点在输入上的间距：

$$
r_l = r_{l-1} + (k_l - 1)\, j_{l-1},
\qquad
j_l = j_{l-1}\, s_l
$$

  初值 $r_0 = j_0 = 1$，池化也算一层。两个 $3\times3$ 卷积（步长 1）的感受野是 $5\times5$，三个是 $7\times7$。下采样越早，后面每一层的感受野增长越快。
- 理论感受野不等于有效感受野：实际起作用的范围集中在中心，比理论值小得多。

## 演进

1. **LeNet（1998）到 AlexNet（2012）**：卷积加池化的组合在 AlexNet 上第一次在大规模图像分类中胜出，ReLU、Dropout 和 GPU 训练都在这一步成熟。
2. **VGG（2014）与 ResNet（2015）**：VGG 用堆叠的 $3\times3$ 卷积代替大核，同样的感受野参数更少、非线性更多；ResNet 用残差连接让网络可以训练到上百层。
3. **深度可分离卷积（2016–2018）**：Xception、MobileNet 把卷积拆成深度卷积和逐点卷积；MobileNetV2 进一步提出「先升维、做深度卷积、再降维」的倒残差结构。
4. **ViT（2020）**：去掉卷积，图像切块后直接交给标准 Transformer 编码器。DeiT 随后表明，配合强数据增强和蒸馏，只用 ImageNet 也能训好。
5. **互相借鉴（2021–2022）**：Swin 给 Transformer 加回层级结构和局部窗口注意力；ConvNeXt 把 Transformer 时代的设计（大核深度卷积、LayerNorm、GELU 等）搬回 CNN，性能追平。两条路线的差距主要来自训练方法和设计细节，而不是算子本身。

## 标准卷积 → 深度可分离卷积

标准卷积在一个核里同时完成空间聚合和通道混合。深度可分离卷积把它拆成「深度卷积 + $1\times1$ 逐点卷积」两步，参数量和乘加量都按同一个比例下降：

$$
\frac{C_i k^2 + C_o C_i}{C_o C_i k^2} = \frac{1}{C_o} + \frac{1}{k^2}
$$

$k=3$、通道数较大时约省 $8 \sim 9$ 倍。以 $64 \to 128$ 通道、$3\times3$ 为例，参数量从 $73728$ 降到 $8768$。

用理论计算量衡量会高估收益：深度卷积每读一个数据只做很少的乘加，在 GPU 上是访存受限的，实际延迟的下降通常小于理论比例。MobileNet 的设计目标是端侧的参数量和计算量，不是 GPU 上的吞吐。

## CNN 与 ViT 的归纳偏置

**归纳偏置**（inductive bias）是模型结构里预先假定的规律。CNN 把局部性和平移等变写进了结构，ViT 几乎没有：

| | CNN | ViT |
| --- | --- | --- |
| 局部性 | 内置，核只看邻域 | 没有，注意力第一层起就是全局 |
| 平移等变 | 内置，权重共享 | 靠数据学出来 |
| 位置信息 | 隐含在滑动窗口里 | 要显式加位置嵌入 |
| 数据需求 | 较少 | 大，靠大规模预训练或强增强 |
| 随分辨率的代价 | 与像素数成正比 | 注意力随 token 数平方增长 |

说明：

- **平移等变**指输入平移，输出同样平移，即 $f(\operatorname{shift}(x)) = \operatorname{shift}(f(x))$。卷积满足它（忽略边界；有步长时只对步长的整数倍平移成立），池化再加上最后的全局池化，才带来近似的**平移不变**。
- ViT 的 patch 投影和 MLP 对每个 token 用同一套权重，这部分也是平移等变的；打破等变的是位置嵌入，以及注意力对位置的依赖。
- ViT 原论文的结论：只在 ImageNet 这种规模的数据上训练，ViT 不如同量级的 ResNet；在更大的数据集（如 JFT-300M）上预训练后才反超。偏置越少，越需要数据来补。
- 反过来，偏置是把双刃剑：数据足够多时，硬编码的局部性反而限制了模型。

## CLS token 与平均池化

Transformer 输出的是 $N$ 个 token，分类还需要**一个**向量代表整张图，有两种取法：

- **CLS token**：在序列开头拼一个可学习的向量（沿用 BERT 的做法），经过所有块之后，只取它的输出接分类头。信息通过注意力从各个 patch 汇入它。序列长度因此是 $N+1$，ViT 块的输入就是这个形状。
- **全局平均池化**（GAP）：对所有 patch token 的输出取平均，不需要额外的 token。思路和 CNN 里「卷积特征图最后做全局平均池化再接分类头」相同。

两者差别不大：ViT 原论文的对比实验里，二者在调好学习率之后效果相近。GAP 实现更简单，对输入分辨率的变化也更自然；Swin 这类层级式结构没有天然的 CLS 位置，用的是 GAP。CLS 的好处是读出端可以通过注意力自己决定看哪些 patch，而不是平均。

## 怎么选

- **端侧、算力或数据有限**：CNN，尤其是深度可分离卷积系列。
- **大规模预训练、要和文本等其他模态统一**：ViT，序列接口和语言模型一致。
- **高分辨率、密集预测（检测、分割）**：全局注意力太贵，用层级式结构（Swin、ConvNeXt）或窗口注意力。
- **下采样**：池化无参数、实现简单；步长卷积可学习。现代网络两者都有用到。
- **取全局表示**：CLS 与 GAP 差别不大，照所用模型的惯例来；层级式结构选 GAP。

## 题目顺序

1. **二维卷积**：本专题的基础，先学会用 `unfold` 取窗口，以及输出尺寸、填充、步长。
2. **二维最大池化**：复用同一套取窗口的写法，把求和换成取最大，难度最低，巩固 `unfold`。
3. **深度可分离卷积**：仍是 `unfold`，但要分清「哪些维度求和、哪些维度不求和」，并体会参数量的节省。
4. **ViT Patch Embedding**：离开滑动窗口，换成 `reshape` / `permute` 切块，并看到它与卷积的等价。
5. **ViT Transformer Block**：把注意力、LayerNorm、GELU 和残差拼成一个完整的块，是前面所有内容的汇合。

## 面试追问

1. **CNN 的归纳偏置有哪些？为什么它们能省数据？**
   局部性（只看邻域）和平移等变（权重共享）。它们相当于预先告诉模型「图像的规律是局部的、位置无关的」，不必靠数据去学，所以小数据上比 ViT 强，数据足够多时这种偏置反而可能成为限制。

2. **深度可分离卷积比标准卷积省多少？实际延迟也省这么多吗？**
   参数量和乘加量之比都是 $1/C_o + 1/k^2$，$3\times3$ 时约为 $1/8 \sim 1/9$。延迟通常省得少一些：深度卷积算术强度低，在 GPU 上受访存限制。

3. **patch embedding 和卷积是什么关系？**
   块大小为 $P$ 的 patch embedding，等价于核大小和步长都是 $P$ 的卷积，输出通道数是嵌入维度。块不重叠，每块一次线性投影。

4. **CLS token 和平均池化各有什么特点？**
   CLS 是一个额外的可学习 token，靠注意力汇总信息，序列长度多 $1$；平均池化没有额外参数，直接对 patch token 取平均。调好学习率后两者效果接近。

5. **ViT 在更高分辨率上微调时要注意什么？**
   块大小不变时，分辨率变大意味着 token 数变多，注意力代价按平方增长。预训练好的位置嵌入个数也和新的 token 数对不上，常用的做法是把它按二维网格做插值。
