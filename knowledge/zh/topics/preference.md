## 解决什么问题

很多目标说不清「标准答案」，但人能比较两个回答哪个更好。**偏好优化**就是从这类比较数据里学习。共同的出发点是 **Bradley-Terry 模型**：回答 $y_w$ 比 $y_l$ 更受偏好的概率由两者奖励之差决定：

$$
P(y_w \succ y_l \mid x) = \sigma\bigl(r(x, y_w) - r(x, y_l)\bigr)
$$

$\sigma$ 是 sigmoid。用它有两条路：

- **先训奖励模型，再做 RL**：把 $r$ 参数化成一个打分网络，最大化偏好对的似然（「Bradley-Terry 奖励模型」一题），再用 PPO、GRPO 优化策略（见「强化学习对齐」专题）。
- **直接优化策略**：DPO 一族把奖励换成策略自己的对数概率比，跳过奖励模型和在线采样，训练过程就像监督学习。

## DPO 为什么能省掉奖励模型

带 KL 约束的目标 $\max_\pi \mathbb{E}[r] - \beta \operatorname{KL}(\pi \Vert \pi_{\text{ref}})$ 有闭式最优解 $\pi^* \propto \pi_{\text{ref}}\, e^{r/\beta}$，反过来，奖励可以用策略表示：

$$
r(x, y) = \beta \log \frac{\pi^*(y \mid x)}{\pi_{\text{ref}}(y \mid x)} + \beta \log Z(x)
$$

Bradley-Terry 只看两个回答的奖励之差，同一个 $x$ 下的 $\beta \log Z(x)$ 相减抵消。代回去得到 DPO 损失：

$$
L_{\text{DPO}} = -\log \sigma\bigl(\beta\, h\bigr), \qquad h = \log \frac{\pi_\theta(y_w)}{\pi_{\text{ref}}(y_w)} - \log \frac{\pi_\theta(y_l)}{\pi_{\text{ref}}(y_l)}
$$

$\beta \log(\pi_\theta / \pi_{\text{ref}})$ 叫**隐式奖励**。代价是 DPO 是**离线**的：偏好数据通常来自别的模型，策略训练过程中自己的分布变了，数据却不变。

## 对比

| 方法 | 需要 reference | 数据 | 损失的核心 | 主要改动 |
| --- | --- | --- | --- | --- |
| DPO | 是 | 成对偏好 | $-\log\sigma(\beta h)$ | 基线；reference 的对数概率可以预先算好，训练时只需一个模型在显存里 |
| IPO | 是 | 成对偏好 | $(h - \tfrac{1}{2\beta})^2$ | 回归到固定间隔，不会无限推大 $h$ |
| cDPO | 是 | 成对偏好（可能有噪声） | 标签平滑的 DPO | 假设一部分偏好标反了 |
| SimPO | 否 | 成对偏好 | $-\log\sigma\bigl(\beta(\bar\ell_w - \bar\ell_l) - \gamma\bigr)$ | 用按长度平均的对数概率当奖励，加间隔 $\gamma$ |
| ORPO | 否 | 成对偏好 | SFT 损失 + 对数几率比项 | 把 SFT 和偏好优化合成一步 |
| KTO | 是 | 单条「好 / 坏」标签 | 相对参考点的前景理论效用 | 不需要成对数据 |

$\bar\ell$ 表示按 token 数平均的对数概率。

## 演进

1. **奖励模型 + PPO（2017–2022）**：偏好先变成奖励模型，再做 RL，即 InstructGPT 的流程。
2. **DPO（2023）**：推出闭式解，直接在偏好对上训练。
3. **针对 DPO 弱点的修补（2023–2024）**：
   - **IPO**：偏好几乎确定时，DPO 会把 $h$ 一直推大、过拟合，IPO 改成回归到固定目标。
   - **cDPO**：给标签加平滑，应对标注噪声。
   - **KTO**：只要单条好坏标签，数据更容易收集。
   - **ORPO、SimPO**：去掉 reference，省一个模型；SimPO 按长度平均，缓解偏爱长回答的问题。
4. **在线化（2024 起）**：用当前策略生成回答，再用奖励模型或评审模型标出偏好对，迭代地做 DPO（iterative / online DPO），弥补离线数据分布过时的问题。

## DPO 一族的常见现象

- **被选中回答的对数概率也在下降**：DPO 只要求 $h$ 变大，两边可以一起降，只是被拒的降得更快。被选中回答的概率下降，意味着概率质量流到了数据之外的回答上，可能伤害生成质量。常见对策是加一点 SFT 损失（ORPO 就是这么做的）；调大 $\beta$、让策略更贴近 reference，有时也能缓解。
- **长度作弊**：隐式奖励是对数概率之和，长回答的绝对值更大，模型容易学会写长。SimPO 的长度平均、R-DPO 一类的长度正则都针对这一点。
- **$\beta$ 的作用**：$\beta$ 越小，越允许偏离 reference，训练信号也越激进。
- **数据分布**：偏好对最好来自和当前策略相近的模型，否则策略学的是「别人的回答哪个更好」。

## 怎么选

- **有成对偏好、想要稳定简单**：DPO，标注噪声大就用 cDPO。
- **偏好几乎确定、担心过拟合**：IPO。
- **显存紧、不想放 reference**：SimPO 或 ORPO；ORPO 还能省掉单独的 SFT 阶段。
- **只有点赞 / 点踩这类单条反馈**：KTO。
- **有能自动判对错的任务**：在线 RL 通常比离线偏好优化效果更好，见「强化学习对齐」专题。

## 题目顺序

1. **Bradley-Terry 奖励模型**：成对偏好的基础损失，DPO 直接复用它的形式。
2. **DPO 损失**：把奖励换成策略与参考模型的对数概率比。
3. **DPO 变体：IPO / cDPO / SimPO / ORPO**：四种改法放在一起比较，各自改了 DPO 的哪一处。
4. **KTO 损失**：从成对数据换到单条好坏标签，引入参考点。

## 面试追问

1. **DPO 的推导关键在哪？**
   带 KL 约束的奖励最大化有闭式最优解，于是奖励能用策略和参考模型的对数概率比表示；代入 Bradley-Terry 后配分函数 $Z(x)$ 抵消，得到只依赖策略的监督式损失。
2. **DPO 真的不需要强化学习吗？**
   它不需要显式奖励模型和在线采样，但优化的仍是带 KL 约束的 RL 目标，隐式奖励是 $\beta \log(\pi_\theta / \pi_{\text{ref}})$。代价是离线、依赖偏好数据的分布，也依赖 Bradley-Terry 假设。
3. **为什么 DPO 训练中被选中回答的对数概率也会下降？**
   损失只约束两者之差，不约束各自的绝对值。两边一起降、被拒的降得更快，损失照样下降。可以加 SFT 损失或调大 $\beta$ 来缓解。
4. **SimPO 和 ORPO 为什么能去掉 reference？**
   SimPO 直接用按长度平均的对数概率当奖励，再加一个间隔；ORPO 用 SFT 损失本身拴住模型，再加一个比较两回答几率的项。两者都不需要 reference 提供的锚点。
5. **离线偏好优化和在线 RL 怎么选？**
   离线方法便宜、稳定，但数据分布不随策略更新；在线 RL 用策略自己的样本，能持续探索和纠错，效果通常更好，代价是要生成和打分。折中做法是迭代 DPO：每轮用当前策略生成新的偏好对。
