## 背景

用 RoPE 训练的模型，在长度超过训练上下文（比如 4K）的序列上效果会急剧下降：低频维度的旋转角度 $m\,\theta_i$ 超出了训练时见过的范围。

两种不重新训练就扩展上下文的做法：

- **位置插值**（PI）：把位置除以 $s$，$m \to m/s$。所有角度都回到训练范围内，但高频维度也被压缩了，相邻 token 之间的角度差变成原来的 $1/s$，局部分辨率下降。
- **NTK-aware 缩放**：不动位置，改 RoPE 的**底数**。高频维度几乎不变（保留局部细节），低频维度被拉伸（容纳更长距离）。

## 核心公式

标准 RoPE 的频率（$b = 10000$）：

$$
\theta_i = b^{-2i/D}, \qquad i = 0, 1, \dots, \tfrac{D}{2} - 1
$$

NTK-aware 缩放把底数换成

$$
b' = b \cdot s^{D/(D-2)}
$$

其中 $s$ = 新上下文长度 / 训练长度。然后用 $b'$ 做标准 RoPE。

**为什么是这个指数**：看两端的频率。

- 最高频 $i = 0$：$\theta'_0 = b'^{\,0} = 1 = \theta_0$，**完全不变**。
- 最低频 $i = \tfrac{D}{2} - 1$，指数为 $-\tfrac{D-2}{D}$：

$$
\theta'_{\text{last}} = \bigl(b\, s^{D/(D-2)}\bigr)^{-(D-2)/D} = b^{-(D-2)/D} \cdot s^{-1} = \frac{\theta_{\text{last}}}{s}
$$

最低频恰好缩小为 $1/s$，和位置插值的效果一样。中间的维度在两者之间平滑过渡。

## 形状

和 RoPE 相同：`q`、`k` 为 `(B, S, D)`，角度表为 `(S, D/2)`，输出形状不变。

## 用到的 PyTorch 操作

和 RoPE 一题相同：`torch.arange`、`torch.cos` / `torch.sin`、`x[..., 0::2]` / `x[..., 1::2]`、`torch.stack(..., dim=-1).flatten(-2)`。底数是一个 Python 浮点数，用 `**` 计算。

## 常见坑

- **指数写成 $D/(D-1)$ 或 $D/2$**：正确的指数是 $D/(D-2)$，它保证最低频恰好缩小 $s$ 倍。
- **去缩放位置**：NTK 方法不改位置 $m$，只改底数。
- 自检：$s = 1$ 时 $b' = b$，结果必须和标准 RoPE 完全一致。
- 旋转本身的约定（奇偶配对、交错拼回）和 RoPE 一题相同。

## 延伸

- **逐维的缩放比**：新旧频率之比为

$$
\frac{\theta'_i}{\theta_i} = \frac{b'^{-2i/D}}{b^{-2i/D}} = s^{-2i/(D-2)}
$$

指数随 $i$ 线性增大：$i = 0$ 时比值为 $1$，最后一对为 $s^{-1}$，在对数坐标下均匀过渡。这解释了「高频几乎不动，低频接近位置插值」。
- **不是精确插值**：位置插值把所有维度统一压缩 $s$ 倍，所有角度都落回训练范围内；NTK-aware 的中间维度压缩得不够，仍可能出现略超出训练范围的角度。这是 YaRN 按波长分段处理的动机，见「位置编码」专题。
- **动态 NTK**：不固定 $s$，而是取 $s = \max(1, \text{当前长度} / \text{训练长度})$。序列没超过训练长度时 $s = 1$，不做缩放，对短序列没有影响。实现时要注意：缓存里的 $k$ 是按旧底数旋转的，底数一变就和新的 $q$ 对不上了。
- **和微调的关系**：NTK-aware 缩放的卖点是不微调也能直接用，用少量长文本微调通常效果更好。
- **另一条路**：预训练或继续训练时直接使用更大的底数，例如 Code Llama 的 $10^6$，LLaMA 3 的 $5 \times 10^5$，让模型从一开始就学习适应长距离。
- **代价**：只改了 $\cos$、$\sin$ 表的频率，没有额外参数和计算。

## 面试追问

1. **RoPE 模型为什么超出训练长度后效果会变差？**
   低频维度在训练窗口内只转过很小的角度，超出之后出现训练中没见过的大角度，注意力分数的分布偏离训练时的样子。高频维度早已转过许多圈，见过各种相位，不是问题的来源。
2. **位置插值和 NTK-aware 缩放有什么区别？**
   位置插值把位置除以 $s$，所有频率都被压缩 $s$ 倍，代价是高频维度的分辨率下降，相邻 token 难区分。NTK-aware 改的是底数，高频几乎不动，低频接近压缩 $s$ 倍，中间平滑过渡。
3. **为什么底数的指数是 $D/(D-2)$？**
   最高频 $i=0$ 的频率恒为 $1$，不受底数影响。最低频的指数是 $-(D-2)/D$，要让它恰好缩小为原来的 $1/s$，底数就要乘以 $s^{D/(D-2)}$。
4. **动态 NTK 缩放是什么？**
   让 $s$ 随当前序列长度变化，不超训练长度时不缩放，序列变长时才逐步加大底数。好处是短序列的表现不受影响，代价是缓存的 $k$ 在底数变化时需要重新旋转。
5. **YaRN 在 NTK-aware 的基础上改了什么？**
   按每个维度的波长相对于训练长度分段：波长很短的维度不动，波长很长的按 $1/s$ 插值，中间线性过渡；另外对注意力分数做温度修正，补偿序列变长后分布变平的问题。
