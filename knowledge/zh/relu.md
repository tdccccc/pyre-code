## 背景

神经网络由一层层线性变换叠起来。如果层与层之间什么都不加，多层线性变换合起来仍然是一个线性变换：

$$
W_2 (W_1 x) = (W_2 W_1)\, x
$$

再深的网络也只相当于一层。**激活函数**插在线性层之间，引入非线性，网络才能拟合复杂函数。ReLU 是最简单、用得最多的一种。

## 核心公式

$$
\mathrm{ReLU}(x) = \max(0, x) =
\begin{cases}
x, & x > 0 \\
0, & x \le 0
\end{cases}
$$

它的导数（反向传播时用到）：

$$
\frac{\mathrm{d}}{\mathrm{d}x}\mathrm{ReLU}(x) =
\begin{cases}
1, & x > 0 \\
0, & x < 0
\end{cases}
$$

在 $x = 0$ 处不可导，实际实现中一般取 $0$。正半轴梯度恒为 $1$，所以深层网络里梯度不容易像 sigmoid 那样越乘越小。

## 用到的 PyTorch 操作

- **逐元素运算**：`x * y`、`x > 0` 等对张量的每个元素分别计算，输出形状和输入相同。
- **布尔掩码**：`x > 0` 得到 `bool` 张量；参与乘法前可以用 `.float()` 或 `.to(x.dtype)` 转成数值。
- `torch.clamp(x, min=0)`、`torch.maximum(x, torch.zeros_like(x))` 也能表达 $\max(0, x)$。

## 常见坑

- **用 Python 的 `max(0, x)`**：它比较的是整个对象，不是逐元素比较，对多元素张量会报错。
- **断开梯度**：用 `x.detach()`、`.numpy()` 或者新建张量再赋值，结果就不再连在计算图上，测试里 `backward()` 拿不到梯度。
- **原地修改输入**：比如 `x[x < 0] = 0` 会改掉调用者传进来的张量，对需要梯度的叶子张量还会直接报错。
- **只支持某个形状**：输入可以是任意形状，逐元素运算天然满足，不要写死维度。

## 延伸

- **为什么比 sigmoid 好训**：sigmoid 的导数最大只有 $1/4$，反向传播时每过一层就乘一次这样的小数，层数一多梯度趋近于零。ReLU 在正半轴导数恒为 $1$，梯度可以原样穿过激活的神经元。
- **成本很低**：前向只有一次比较，反向只需要知道「输入是否为正」这一个掩码。因为 ReLU 的输出为正当且仅当输入为正，反向可以直接用输出算出掩码，所以 `nn.ReLU(inplace=True)` 可以安全地覆盖输入，省下一份激活内存。（前提是上一层的反向不需要原来的输入，这个前提不总成立，用之前要确认。）
- **稀疏激活**：对零均值的输入，大约一半的神经元输出为 $0$。这种稀疏性有时被用来加速推理，跳过为零的神经元。
- **Dead ReLU**：如果某个神经元的输入在所有样本上都为负（例如学习率过大，一次更新把偏置推到很负），它的输出和梯度永远是 $0$，再也无法恢复。常见缓解办法：
  - Leaky ReLU：负半轴改成 $\alpha x$（$\alpha$ 取很小的常数，如 $0.01$）。
  - PReLU：把 $\alpha$ 变成可学习参数。
  - 用更小的学习率，配合合适的初始化与归一化。
- **分段线性**：由 ReLU 和线性层组成的网络整体是一个分段线性函数，线性区域的数量可以随深度快速增长，这是它表达能力的来源之一。
- **和初始化配套**：ReLU 会清零一半输入，所以要配 Kaiming 初始化（方差 $2/n_{\text{in}}$），见「Kaiming 初始化」一题。
- **在 Transformer 里**：原始 Transformer 的 FFN 用的是 ReLU；后来的 BERT、GPT 换成 GELU，LLaMA 换成 SwiGLU（见「基础层与激活」专题）。

## 面试追问

1. **ReLU 相对 sigmoid / tanh 有什么优点和缺点？**
   优点：计算简单、正半轴梯度恒为 $1$（缓解梯度消失）、输出稀疏。缺点：输出不是零均值；负半轴梯度为零，可能出现 Dead ReLU；在 $0$ 处不可导。
2. **ReLU 在 $0$ 处不可导，为什么没问题？**
   输入恰好等于 $0$ 是个很小概率的事件，实际中任取 $0$ 到 $1$ 之间的任何值作为次梯度都不影响训练。PyTorch 取 $0$。
3. **什么是 Dead ReLU？怎么缓解？**
   神经元的输入永远为负，输出和梯度都是 $0$，参数不再更新。可以用 Leaky ReLU / PReLU、降低学习率、合适的初始化或加归一化。
4. **为什么神经网络需要非线性激活？**
   多层线性层合起来仍是线性映射，加了非线性才能逼近复杂函数。
5. **为什么现在的 Transformer 不再用 ReLU 了？**
   GELU、SwiGLU 这类平滑、带门控的激活在大模型上的实验效果更好，而计算开销相对整个 FFN 的矩阵乘可以忽略。ReLU 并没有被淘汰，在 CNN 和对延迟敏感的场景仍然常用。
